# Moonshot Pinball 1.0: one-page scope

The working list. The long reference is [`../PROTOTYPE_TO_PRODUCT_ROADMAP.md`](../PROTOTYPE_TO_PRODUCT_ROADMAP.md).

**The test for anything new:** does it make the game noticeably more fun or more shippable, or only bigger? If only bigger, it goes on the Later list.

## The game
A portrait, phone-first baseball pinball roguelite that plays in the browser.
- Each run has 5 innings × Starter, Reliever and Closer, so 15 challenges.
- You time swings to launch the ball around the table, draft and buy machines, and grow the table (the Upper Deck after C3) into a ridiculous scoring machine.
- Free to play on itch, with a suggested $0.99.
- It can be added to the Home Screen as an app on iPhone and Android.

## Save & continue (v1, Nov 21): how it behaves
- **Saved automatically** at: each challenge's start card, after every drain (between pitches), the free pick, and the shop (after each pick, buy, sale and reroll). One save per run route, on this device only.
- **Reload mid-pitch:** the game comes back to the start of that pitch, with the score, strikes, multiplier, multiball charge, bank lamps and Rally Fuel it had then. Points scored during the interrupted pitch are lost, so there's nothing to gain from reloading.
- **On return:** a "Continue your run?" card shows the saved table behind it. CONTINUE resumes. NEW RUN asks to confirm ("This ends your saved run for good").
- **When a run ends** (won or failed), its save is cleared.
- **Safety:**
  - A corrupt save, or one from a newer version, is moved aside (`…:unreadable`), never deleted, and the player is told.
  - A machine that no longer fits after a game update is refunded, not lost.
  - Blocked storage (private mode) means the game just runs without saving.
- **Known limits:**
  - Two tabs of the same route: the last one to save wins.
  - Developer analytics start a fresh run record on resume.
